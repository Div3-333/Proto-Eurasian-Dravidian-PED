# Proto-Eurasian-Dravidian (PED) Research Project

## Overview
This project aims to reconstruct the Proto-Eurasian-Dravidian (PED) macro-family using an iterative "Research -> Execute -> Peer Review" cycle. We utilize both traditional historical linguistics and modern computational simulations to validate our hypotheses.

## Directory Structure
- `src/`: Python scripts for linguistic simulations, phonetic alignment, and statistical analysis.
- `data/`: Reconstructed proto-roots, phoneme frequency tables, and lexical datasets for PIE, PD, and PST.
- `docs/`: Academic reports, meeting notes, and peer review transcripts.
- `simulations/`: Results and visualizations from computational experiments.

## Current Hypothesis: The Glottalic Architecture
Our primary hypothesis focuses on a shared ejective consonant system and Active-Stative morphosyntax dating back to 30,000-40,000 BP.

## Computational Strategy
We use Monte Carlo simulations to model lexical decay over deep time, allowing us to identify the "stability threshold" for core vocabulary. This provides a statistical basis for rejecting the null hypothesis (coincidental look-alikes).
