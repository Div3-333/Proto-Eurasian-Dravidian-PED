\section{The Held-Out Data Protocol}
To address the charge of "pre-emptive translation" and "template injection," we executed a Zero-Shot validation protocol. We purged all Sanskrit glosses and translations from the corpus, reducing it to a purely structural sequence of numeric sign IDs. We then split the corpus into a Training Set (80\%) and a Held-out Validation Set (20\%).

The model was trained entirely on the first 80\%, meaning it had **zero exposure** to the final 20\% of the archaeological record.
